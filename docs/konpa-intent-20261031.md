# 空巴意向与确认

经用户批准，班会上下午签到均增加明确空巴选择；上午用于订餐，下午选择参加先待确认。班主任、副班主任、班长可调整及最终确认；组长、辅导员只查看本组，组织范围由统一平台实时校验，经现有服务密钥传入可信范围。

空巴正式结束后满7×24小时，未核实的参加记录自动确认；人工不参加和已确认记录受到保护。自动检查触发器为konpaAutoConfirmEvery5Minutes，建议cron为0 */5 * * * * *。部署须保留线上现有全部触发器、身份、环境与资源。

确认与订餐快照使用既有config集合的专用确定前缀，复用events、registrations、checkins和event_audit_logs，不新增集合或SQL结构。对外名单仅包含必要姓名、小组及状态，不返回联系方式。事务内复核活动和报名、校验版本、写唯一签到、同步状态及审计，重复任务不重复签到；取消活动不确认。确认后纠正通过撤销标记和递增来源版本体现，原事实保留，可恢复。

KONPA_INTENT_ENABLED=true开启小程序必选校验；必须等待具备该界面的小程序正式版发布后启用。未开启时既有签到行为保持兼容；一周自动任务只处理已明确登记的本功能记录。开发版上传不等同于正式发布。

验证包括原生签名票据入口未选择拒绝、false正常签到、不提前生成空巴签到，以及人工确认/纠正经考勤拉取返回PRESENT/ABSENT及递增revision；另覆盖一周边界、并发、角色范围、隐私和订餐快照。
